# Artifacts

Saved trained model files for this project (e.g. .pkl, .joblib), produced by the training scripts in src/models/. These are the persisted outputs of Model 1 and Model 2, as described in the project's SS2 documentation (src/models/README.md, Model1.MD, Model2.MD).

Large model files are excluded from version control via .gitignore; only this README is tracked. Refer to src/models/ for the code used to generate these artifacts.
