# Artifacts

Saved trained model files for this project (e.g. .pkl, .joblib), produced by the model notebooks in src/models/: `model1_logistic_regression.ipynb` writes `model1_logistic_regression.pkl` and `model1_scaler.pkl`, and `model2_xgboost.ipynb` writes `model2_xgboost.pkl`. These are the persisted outputs of Model 1 and Model 2, as described in the project's SS2 documentation (src/models/README.md, Model1_Logistic_Regression.MD, Model2_XGBoost.MD).

Large model files are excluded from version control via .gitignore; only this README is tracked. Refer to src/models/ for the code used to generate these artifacts.
