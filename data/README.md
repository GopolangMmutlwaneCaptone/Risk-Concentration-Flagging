# Data

Raw and processed datasets used in this project.

- `data/raw/`: SEC Form 13F institutional holdings data, used as a public proxy dataset for SS2 (see root README for download instructions). Not committed due to size.
- `data/raw/client_extract/`: the real STADIOEquities client data extract received for SS3, used to apply the SS2-validated methodology to actual client data. Not committed (contains client-level data); see [`data/raw/client_extract/README.md`](raw/client_extract/README.md) for schema and data quality notes.
- `data/processed/`: files generated by running the SS2 notebooks in order (mapped tickers, price history, engineered features), including the checkpoints written during the ticker and sector lookups. Not committed (git-ignored).
